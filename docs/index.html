Building an IoT node from bare registers up.

A dual-MCU IoT node — STM32F411 for sensing and control, ESP32 for the radio — written without a vendor HAL or framework. Every peripheral driver, every clock calculation, every fault handler, by hand. This page tracks it as it happens.

Now bringing up

what's under the probe this week

UART

Polling, then interrupts

Validating the USART peripheral by polling SR/DR before touching NVIC — register read order matters, since both SR and DR clear flags on access. ISR-driven RX with a ring buffer is next.

CLOCK

25MHz HSE → 100MHz core

Crystal-mode HSE (not bypass), PLLM/25 · PLLN/200 · PLLP/2, VOS scale 1, 3 wait-state flash latency, APB1 at /2 for 50MHz peripheral clock.

DEBUG

OpenOCD over telnet

Live register readback to verify hardware state — resume/halt cycles to see runtime values, not just power-on-reset defaults.
